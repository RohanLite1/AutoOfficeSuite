OFFICE AUTOMATION PORTABLE BUNDLE - USER GUIDE
Estimate Reconciler, Parts & Labour Extractor, and Insurance MIS Suite
================================================================================

This portable bundle can be transferred to ANY Windows 10 / 11 PC via USB drive,
email, Google Drive, or shared folder. No Python installation required!

--------------------------------------------------------------------------------
1. WHAT IS IN THIS BUNDLE
--------------------------------------------------------------------------------
1. OfficeAutomation.exe
   - Standalone Windows Desktop App with its own window.
   - Built-in Native Windows File Explorer file picker.
   - Direct disk editing: updates your original spreadsheet on your drive!
   - Built-in live audit indicators and confirmation badges.

2. extension/ & Office_MIS_Extension.zip
   - 1-Click Chrome Extension for Universal Sompo & Insurance Claim Portals.
   - Once loaded into Chrome, it stays permanently installed on that machine.

3. HOW_TO_USE_ON_ANY_PC.txt
   - This setup and user guide.


--------------------------------------------------------------------------------
2. HOW TO RUN THE DESKTOP APP
--------------------------------------------------------------------------------
1. Extract this entire zip into any folder of your choice (e.g. Desktop\OfficeApp\
   or D:\OfficeAutomation\).
2. Double-click "OfficeAutomation.exe".
3. A clean desktop application window opens immediately!


--------------------------------------------------------------------------------
3. THE 4-STEP ESTIMATE & FINAL BILL RECONCILER
--------------------------------------------------------------------------------
The top ribbon guides you horizontally through the 4 steps:

STEP 1: Assessment Excel
   - Click "📁 Add Excel File" to select your master assessment spreadsheet (.xls or .xlsx).
   - Configure your target Sheet (e.g. Sheet1), Parts Starting Row (default 171),
     and Labour Starting Row (default 359).
   - The app links the real file directly on disk with automatic safety backups (.bak).

STEP 2: Estimate PDF Bill
   - Click "📄 Add Estimate PDF" to select your dealer / workshop repair estimate PDF.
   - Automatically parses all parts and labour with Taxable Amounts (excluding GST).
   - Both Parts and Labour are extracted and ready to write.
   - Click "📦 Write Parts to Excel" to paste parts into Row 171 (Col C Particular, Col D Estimate).
   - Click "🛠️ Write Labour to Excel" to paste labour charges into Row 359 (LABOUR COMPUTATION).
   - Column B (Bill No) is intentionally left blank per user requirements.

STEP 3: Import Bill PDF
   - Click "📥 Import Bill PDF" to select your final workshop tax invoice PDF.
   - Automatically extracts parts, labour, and billed amounts.

STEP 4: Tally Parts and Paste Cost
   - Click "⚡ Tally & Paste Cost" to automatically reconcile Step 2 parts against Step 3 bill.
   - QUANTITY LIMITING: If the final bill has more parts than estimated (e.g. 20 clips in
     bill but only 1 clip in estimate), the app automatically limits the bill quantity
     to the estimate limit (at max) and calculates the cost accordingly.
   - INTERACTIVE QUANTITY STEPPER: In the tally table, use the "−" and "+" buttons or type
     directly in the Parts Qty input. The assessed cost recalculates in real-time
     (e.g. 2 parts @ 100Rs -> drop to 1 part -> 50Rs).
   - MATERIAL CATEGORIZATION: Automatically tags each item:
       * Metal (Col E)
       * Non-Metal (Col F)
       * Glass (Col G)
       * Not Allowed (Col H - Yellow cell for parts in estimate but not in final bill)
     You can also click any category button to adjust the destination column manually.
   - Click "✍️ Write Tallied Costs to Excel" to paste the assessed costs into their designated
     columns (Col E, Col F, Col G, Col H).


--------------------------------------------------------------------------------
4. HOW TO VERIFY CHANGES MADE TO YOUR EXCEL SPREADSHEET
--------------------------------------------------------------------------------
To guarantee you always know if and where your spreadsheet was updated:

1. Live Target Excel Status Strip:
   - Green indicator confirms connected file, active sheet, last save time, and file size.

2. Post-Save Audit Confirmation Modal:
   - After writing parts, labour, or tallied costs, a confirmation popup shows:
     * Sheet name and exact start/end rows written.
     * Category distribution breakdown.
   - 1-Click Buttons:
     * [ 📂 Open in Excel ]: Launches the updated spreadsheet in Microsoft Excel.
     * [ 📁 Explorer ]: Opens the folder in Windows Explorer with the file selected.


--------------------------------------------------------------------------------
5. HOW TO INSTALL THE CHROME EXTENSION ON ANY MACHINE (PERMANENTLY)
--------------------------------------------------------------------------------
You DO NOT need to pay or go through the Chrome Web Store review process.
By loading it as an unpacked extension from your local folder, Chrome keeps it
installed permanently on that computer:

1. Open Google Chrome.
2. In the URL bar, type:
      chrome://extensions
   and press Enter.
3. In the top-right corner, turn ON the switch that says "Developer mode".
4. In the top-left corner, click the "Load unpacked" button.
5. In the file picker dialog, select the "extension" folder inside this bundle.
6. Click "Select Folder".
7. DONE!
   - The extension will appear in your Chrome toolbar.
   - Pin "Office MIS Claim Assistant" for quick 1-click access.


--------------------------------------------------------------------------------
6. TROUBLESHOOTING & TIPS
--------------------------------------------------------------------------------
- "File is locked / Permission Error":
  Microsoft Excel locks files exclusively when open. If the app displays a lock warning,
  simply save and close the file in Excel, then click Write again.
- "Different PC Paths":
  When moving the bundle to another computer, click "📁 Change File" once to select
  where the assessment spreadsheet is stored on that new computer.
