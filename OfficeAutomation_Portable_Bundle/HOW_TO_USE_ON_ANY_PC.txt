OFFICE AUTOMATION PORTABLE BUNDLE - USER GUIDE
For Insurance Claim MIS Extractor & Estimate Assessment
================================================================================

This portable bundle can be transferred to ANY Windows 10 / 11 PC via USB drive,
email, Google Drive, or shared folder. No Python installation required!

--------------------------------------------------------------------------------
1. WHAT IS IN THIS BUNDLE
--------------------------------------------------------------------------------
1. OfficeAutomation.exe
   - Standalone Windows Desktop App with its own window.
   - Built-in Native Windows File Explorer file picker.
   - Direct disk editing: updates your original spreadsheet on your drive!
   - Built-in live audit indicators and confirmation badges.

2. extension/ & Office_MIS_Extension.zip
   - 1-Click Chrome Extension for Universal Sompo & Insurance Claim Portals.
   - Once loaded into Chrome, it stays permanently installed on that machine.

3. HOW_TO_USE_ON_ANY_PC.txt
   - This setup and troubleshooting guide.


--------------------------------------------------------------------------------
2. HOW TO RUN THE DESKTOP APP
--------------------------------------------------------------------------------
1. Extract this entire zip into any folder of your choice (e.g. Desktop\OfficeApp\
   or D:\OfficeAutomation\).
2. Double-click "OfficeAutomation.exe".
3. A clean desktop application window opens immediately!


--------------------------------------------------------------------------------
3. LINKING YOUR EXCEL SPREADSHEETS (BROWSE FEATURE IMPROVEMENTS)
--------------------------------------------------------------------------------
On ANY computer, you can link your spreadsheets in 3 easy ways:

A. 📁 "Browse" Button:
   - Click "📁 Browse" next to the Master Excel or Target Excel dropdown.
   - A standard native Windows Explorer dialog will appear.
   - Pick your file from Desktop, Documents, D:\, or Network Drive.
   - The app links the REAL file path directly (NOT a temporary copy).

B. ✏️ "Paste Path" Button:
   - If your file is deep in folders, click "✏️ Paste Path" on the live card.
   - Paste the exact file path (e.g. D:\Office\Claims\MIS-2026.xlsx) and click OK.

C. 📋 Dropdown Selection:
   - The app automatically scans your Desktop, Downloads, and app folders
     for spreadsheets and lists them in the dropdown.


--------------------------------------------------------------------------------
4. HOW TO VERIFY CHANGES MADE TO YOUR EXCEL SPREADSHEET
--------------------------------------------------------------------------------
To guarantee you always know if and where your spreadsheet was updated:

1. Live Target Excel Status Strip:
   - At the top of every tab (MIS Claims, Estimate Parts, MIS from Web), there is
     a dedicated live card:
     * Green Dot: "Active Master Excel (Live)"
     * Disk Path: displays the exact full path to the file being updated.
     * Sheet: displays the active sheet name.
     * Saved At: displays the exact date and timestamp of the last disk save.
     * Size: displays current file size in KB.

2. Post-Save Audit Confirmation Banner:
   - Whenever you click "Append Rows to Master Excel" or "Write Parts to Selected Excel",
     a high-visibility green confirmation box appears at the top:
     * Confirms the exact file name and path updated on disk.
     * Confirms the rows inserted (e.g., Rows 796 to 798).
     * Confirms the file modification time down to the second.
   - Includes 1-Click buttons:
     * [ 📂 Open in Excel to Verify ]: Launches your file in Microsoft Excel immediately.
     * [ 📁 Show in Explorer ]: Opens the folder in Windows Explorer with the file highlighted.
     * [ 📋 Copy Path ]: Copies the path to clipboard.


--------------------------------------------------------------------------------
5. HOW TO INSTALL THE CHROME EXTENSION ON ANY MACHINE (PERMANENTLY)
--------------------------------------------------------------------------------
You DO NOT need to pay or go through the Chrome Web Store review process.
By loading it as an unpacked extension from your local folder, Chrome keeps it
installed permanently on that computer:

1. Open Google Chrome.
2. In the URL bar, type:
      chrome://extensions
   and press Enter.
3. In the top-right corner, turn ON the switch that says "Developer mode".
4. In the top-left corner, click the "Load unpacked" button.
5. In the file picker dialog, select the "extension" folder inside this bundle:
      (e.g., C:\Path\To\OfficeAutomation_Portable_Bundle\extension)
6. Click "Select Folder".
7. DONE!
   - The extension will appear in your Chrome toolbar.
   - Click the puzzle piece icon in Chrome and click the Pin icon next to
     "Office MIS Claim Assistant".
   - It will stay permanently installed on this PC across computer restarts!

HOW TO USE THE EXTENSION:
- Open any Universal Sompo claim page or insurance portal.
- You will see a floating "⚡ Send Claim to MIS" button on the webpage, or
  you can click the extension icon in your Chrome toolbar and click "Send Claim to MIS".
- Ensure OfficeAutomation.exe is running; the claim will instantly appear in the
  "MIS from Web" tab ready to append to Excel!


--------------------------------------------------------------------------------
6. TROUBLESHOOTING & TIPS
--------------------------------------------------------------------------------
- "File is locked / Permission Error":
  Microsoft Excel locks files exclusively when open. If the app displays a lock warning,
  simply save and close the file in Excel, then click Append again.
- "Different PC Paths":
  When moving the bundle to another computer, click "📁 Browse" once to select
  where the MIS spreadsheet is stored on that new computer.
